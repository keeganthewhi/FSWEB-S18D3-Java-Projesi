## About

Covers advanced SQL topics including aggregate functions, grouping, and join operations. This assignment focuses on writing complex queries that combine data from multiple tables.

## Key Concepts

- Aggregate functions: `COUNT`, `SUM`, `AVG`, `MIN`, `MAX`
- `GROUP BY` and `HAVING` clauses
- Join types: `INNER JOIN`, `LEFT JOIN`, `RIGHT JOIN`, `FULL JOIN`
- Subqueries and nested SELECT statements
